# Code of conduct

## The short version

Be decent. Argue with the claim, not the person.

## What this project is about

This repository is a method for **not fooling yourself** about whether a system works. Most
contributions here are disagreements: a rule that does not hold, an example that would pass
against a broken system, a verdict that should have been computed differently. That is the
point, and it is welcome.

So the standard here is deliberately narrow. Contributions are judged on the argument and
the evidence — not on who is making them, how long they have been around, or how confident
they sound.

## Expected

- **Cite something.** A failing case, a line in a spec, a scenario that would pass when it
  should not. "This is wrong" is not reviewable; "this passes at t=0, here is the bundle" is.
- **Assume the other person read carefully.** If a rule looks obviously wrong, the likely
  explanation is a missing piece of context, not carelessness.
- **Say when you have changed your mind.** This project asks systems to report honestly what
  they observed. The same applies to the people writing it.
- **Accept that some disagreements stay open.** Several decisions here were made against
  reasonable objections, and those objections are recorded rather than deleted.

## Not accepted

Harassment, personal attacks, demeaning or discriminatory comments, unwelcome attention, or
publishing anyone's private information. Sustained disruption after being asked to stop.
Deliberately arguing in bad faith — including misrepresenting what someone wrote in order to
rebut it.

None of this becomes acceptable because the technical point underneath it happened to be
correct.

## Scope

Applies in this repository — issues, pull requests, discussions, commit messages, and code
comments — and anywhere someone is representing the project.

## Reporting

Open an issue if it is something the project should discuss in the open. If it is not,
contact the repository owner directly through GitHub ([@bezmoradi](https://github.com/bezmoradi)).

Reports are handled by the repository owner, who will respond as promptly as is practical.
Responses range from a clarifying reply, to a request to edit or withdraw a comment, to
blocking an account. Reporting something in good faith will not be held against you, whatever
the outcome.

Because this project has a single maintainer, there is no independent appeal. That is worth
stating plainly rather than implying a process that does not exist.
